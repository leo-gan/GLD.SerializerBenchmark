# FlatBuffers

[Internals](https://flatbuffers.dev/flatbuffers_internals/) and [FlexBuffers](https://flatbuffers.dev/flexbuffers.html).

Table buffers need generated code, so the table/file-id columns are reject-only well-formedness. FlexBuffers is schemaless and is fully decoded.

XML is intentionally not in this catalog.

Catalog: `compliance/data/flatbuffers/`.
