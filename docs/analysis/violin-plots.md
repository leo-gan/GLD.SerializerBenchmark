# Performance (Violin Plots)

Violin plots show the density of serialize / deserialize timings (wider = more samples at that duration). Generated by `analyze-benchmarks --generate-plots` for every language with CSV logs.

Time axis is **microseconds** (normalized from ticks or nanoseconds in the CSVs). Log scale is used when serializer medians span ≥5×.
