# SBE

Simple Binary Encoding (SBE) 1.0 is a fixed-layout message. The catalog is one raw Signal message. SBE 2.0 is a draft and is not a column. Python has no SBE row. A language with no SBE library has no cell.

Spec: [SBE 1.0 message structure](https://github.com/FIXTradingCommunity/fix-simple-binary-encoding/blob/master/v1-0-STANDARD/doc/03MessageStructure.md).

| Version | Catalog |
|---------|---------|
| 1.0 | `compliance/data/sbe/v1.0.json` |

Pass/fail cells are on the [Dashboard → Compliance](../dashboard/#compliance) view, standard **SBE**.
