### Call-path contract

1. `prepare(fixture)` — untimed  
2. `serializeBytes` / `deserializeBytes` — timed  
3. Stream: **native** or **adapted** (`streamMode`)

## Test data

Suite type ids: `message`, `document`, `telemetry`, `strings`, `event`, plus columnar `table`, `table_project`, `nested_table`, `signal`.  
Smoke filter default: `message`. Columnar runs are bytes-only and use an explicit serializer allow-list. There is no compliance decoder.

`table_project` serializes the full row and deserializes `f_float_0` only (a list, including when N is 1). The runner compares that column.

## Run

```bash
./scripts/run-benchmarks.sh smoke
./scripts/run-benchmarks.sh full
```

Requires **JDK 17+** (21 recommended) and **Maven 3.9+**.

```bash
./scripts/install-host-requirements.sh java
```

`LOG_DIR` may be a logs **root** (results under `$LOG_DIR/java/`).

Analysis: `analyze-benchmarks -l java`.

## Build notes

- Protobuf stubs are generated from `schemas/v2/protobuf/benchmark_v2.proto` via `protobuf-maven-plugin` at build time.
- Avro specific classes for Parquet are generated from a build copy of `schemas/v2/avro` with namespace `benchmark.v2.avro` (the checked-in files stay `benchmark.v2`).
- SBE Java is generated by `sbe-all` 1.40.2. The build copies that jar from Maven and runs it into `target/generated-sources/sbe`. Runtime dependency is Agrona, not the generator.
- Arrow bytes are an IPC stream, not the Arrow file format. `arrow-dataset` is not on the classpath.
- ORC uses `orc-core` and `orc-format` classifier `nohive`. The default `orc-format` jar is `com.google.protobuf` and does not match the nohive writer.
- Shaded jar: `target/serializer-benchmark-java-*-SNAPSHOT.jar`
