# Performance (Violin Plots)

Violin plots show the density of serialize / deserialize timings (wider = more samples at that duration). Generated by `analyze-benchmarks --generate-plots` for **every language with CSV logs** under `logs/<lang>/`.

Time axis is **microseconds** (ticks or nanoseconds from CSVs are normalized first). When serializer medians span **≥5×** (e.g. a slow `cbor` next to fast peers), the x-axis uses a **log scale** so other violins stay readable; otherwise it stays linear. Crowded suites (more than 12 serializers, e.g. C#) plot the **top 5** by mean time; smaller suites plot all serializers. Per-serializer **p99** winsorizing reduces one-off stalls stretching KDE shapes.

Regenerate and refresh this page from reports:

```bash
analyze-benchmarks --generate-plots --output-dir reports
# then copy reports/dashboard/*.png → docs/analysis/dashboard/
# and reports/violin-plots.md → docs/analysis/violin-plots.md (or merge sections)
```
