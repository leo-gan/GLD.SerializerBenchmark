# Thrift

Apache Thrift binary and compact protocols. The catalogs are in-tree. A Python adapter is not wired, so those cells stay empty until a runner decodes them.

| Version | Spec | Catalog |
|---------|------|---------|
| Binary | [Binary protocol](https://github.com/apache/thrift/blob/master/doc/specs/thrift-binary-protocol.md) | `compliance/data/thrift/binary.json` |
| Compact | [Compact protocol](https://github.com/apache/thrift/blob/master/doc/specs/thrift-compact-protocol.md) | `compliance/data/thrift/compact.json` |
