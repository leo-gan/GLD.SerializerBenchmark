# ORC

ORC v1 is the scored columnar file. ORC v2 is a draft and is not a column. `orc` and `orc-uncompressed` share that language’s ORC reader. A language with no ORC library has no cell.

Spec: [ORC v1](https://orc.apache.org/specification/ORCv1/).

| Version | Catalog |
|---------|---------|
| v1 | `compliance/data/orc/v1.json` |

Pass/fail cells are on the [Dashboard → Compliance](../dashboard/#compliance) view, standard **ORC**.
